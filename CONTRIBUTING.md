# Contributing Content

Thank you for improving Archive-Opsec.

## Workflow

1. Create a branch from `main`.
2. Add or update one focused Markdown entry.
3. Include accurate frontmatter and source links.
4. Explain corrections or source changes in the pull request.
5. Open a pull request and wait for editorial review.

The website is built from this repository by a separate private site repository. A content pull request is not published until it has been reviewed and merged, and the site build succeeds.

## New entries

Use nearby entries as structural examples. Guides need a clear description, category, update date, author, and sources. Archive entries also need an event date, status, verification level, summary, claims, and at least one source. News entries are short cited pointers, not republished articles.

## Corrections

Open an issue or pull request with the correction, the affected file, and the source that supports it. For urgent or sensitive corrections, use the contact method listed on the website's methodology page.
